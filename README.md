# Алхимик H₂O-60 — Готовые прошивки (.bin / .hex) и Android (.apk)

Официальный репозиторий готовых прошивок для микроконтроллеров и мобильного приложения системы автоматизации **«Алхимик H₂O-60»**.
За основу прошивки контроллера **Arduino Mega 2560** взят проект [«Доступная автоматика HelloDistiller на Ардуино Мега 2560»](https://forum.homedistiller.ru/index.php?topic=118518.0).

**Актуальная версия:** `v8.0.8`

---

## 📱 Мобильное приложение Android
* **`Alhimik_H2O-60.apk`** — Установочный пакет для смартфона или планшета Android.

---

## ⚡ Бинарные файлы прошивок микроконтроллеров

| Файл | Назначение | Плата |
| :--- | :--- | :--- |
| **`firmware.bin`** | Основная прошивка моста Wi-Fi / Web / MQTT / Telegram | **ESP32-C3** |

| **`esp32_littlefs.bin`** | Файловая система LittleFS с веб-интерфейсом (`0x290000`) | **ESP32 Classic** |
| **`esp32_bootloader.bin`** / **`esp32_partitions.bin`** | Загрузчик и таблица разделов | **ESP32 Classic** |
| **`esp32s3_display_firmware.bin`** | Прошивка сенсорного дисплея 5" IPS 800×480 | **ESP32-8048S050 (ESP32-S3)** |
| **`esp32s3_display_littlefs.bin`** | Файловая система LittleFS с веб-интерфейсом (`0x610000`) | **ESP32-8048S050 (ESP32-S3)** |
| **`esp32s3_display_bootloader.bin`** / **`esp32s3_display_partitions.bin`** | Загрузчик и таблица разделов | **ESP32-8048S050 (ESP32-S3)** |
| **`mega2560_firmware.hex`** | Прошивка силовой автоматики | **Arduino Mega 2560** |

## 🔧 Быстрая прошивка по USB (Windows)
1. Скачайте файлы из последнего релиза (раздел **Releases**) или склонируйте репозиторий.
2. Подключите плату по USB и запустите **`auto_flash_alhimik.bat`** (или скрипт под вашу плату: `flash_esp32c3.bat`, `flash_esp32_classic.bat`, `flash_esp32s3_display.bat`, `flash_mega.bat`).
3. Подключитесь к Wi-Fi сети контроллера `Alhimik_H2O-60_*` (пароль `12345678`), откройте `http://192.168.4.1` и настройте подключение к домашнему роутеру для дальнейших обновлений по воздуху (OTA).
